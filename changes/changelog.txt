scripts/corpus_triage.py  (new)
-------------------------------
Code-driven DELETE / IMPROVE / KEEP verdict per docs/*/post.json.
Outputs: verdicts.json, delete.txt, improve.txt, summary.txt.
Detectors (each based on a defect seen on the live site):
  - truncated title with no recoverable full_title
  - irrelevant "Official documentation" link (label/host not discussed in body)
  - tags that do not appear in the body
  - LLM filler openers
  - templated structure (share of H2 headings reused across >= 8% of posts)
  - first-person experience claims in posts not marked human_reviewed
  - thin posts (< 1000 words DELETE, < 1500 IMPROVE)
Flags:
  --fix                   removes irrelevant doc links and junk tags (backups
                          written to .triage_backups)
  --max-delete-fraction   abort with exit code 3 if DELETE share exceeds this
                          (default 0.25)
Limitations: thresholds are untuned heuristics; review delete.txt before
deleting anything. Near-duplicate detection is left to the existing
adsense_compliance_audit.py.


apply_pipeline_fixes.py  (new)
------------------------------
Idempotent patcher that applies the static_site_generator.py changes above to
your own copy. Fails with an assertion if the expected text is not found
exactly once; writes a .bak backup before changing the file.
