scripts/content_triage.py (new)
-------------------------------
Deterministic DELETE / IMPROVE / KEEP per docs/*/post.json with exact paths
and reasons (thin, near-duplicate, truncated title, templated outline, LLM
filler, unverifiable first-person claims, unsourced numeric claims, tags not
in body). --fix drops absent tags (backups in .triage_backups).
--max-delete-fraction aborts with exit code 3 (default 0.25).
Limitation: thresholds are untuned heuristics.

Failures. Real Fixes.", "no theory, just what's worked in real production

with the site's own disclosure that articles are LLM-drafted and figures are
illustrative.
